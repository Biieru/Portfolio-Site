# Gabriel Araujo | Interactive Portfolio

**Portfólio web desenvolvido com React, Vite, React Router e Framer Motion.**

[**Acessar o projeto**](https://gabriel-caraujo.onrender.com/)

## Sobre o projeto

Projeto autoral de portfólio interativo, desenvolvido para explorar navegação, animações e experiências visuais utilizando tecnologias modernas de front-end.

A aplicação combina componentes React, roteamento entre páginas, transições animadas e recursos multimídia.

## Tecnologias

| Tecnologia | Aplicação |
|---|---|
| React 19 | Componentização e interface |
| Vite 8 | Ambiente de desenvolvimento e build |
| React Router 7 | Navegação |
| Framer Motion | Animações e transições |
| JavaScript | Lógica da aplicação |
| CSS | Estilização |
| ESLint | Análise estática do código |

## Funcionalidades

- Interface de portfólio pessoal.
- Navegação utilizando React Router.
- Transições e animações com Framer Motion.
- Componentes visuais personalizados.
- Integração de áudio ambiente.
- Apresentação de conteúdo profissional.

## Como executar

Clone o repositório:

```bash
git clone https://github.com/Biieru/Portfolio-Site.git
cd Portfolio-Site
```

Instale as dependências:

```bash
npm install
```

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

Para gerar uma versão de produção:

```bash
npm run build
```

Para executar a análise estática:

```bash
npm run lint
```
